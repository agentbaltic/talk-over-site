Talk Over

Install & getting started

Voice-following teleprompter for Mac

Talk Over keeps your script with you while you read. Use a steady timed crawl, work it by hand, or let your voice set the pace. Your scripts and audio stay on your Mac.

What you need

Before you install

Mac
Apple Silicon only: M1, M2, M3, M4 or later.
macOS
macOS 11 Big Sur or later. macOS 13 or later recommended.
Space
About 250 MB free.
Microphone
Any built-in or external mic for voice-following.
Internet
Needed only to download. The app works offline.

Install

Four steps

  1. Download the free trial or purchase Talk Over.
  2. Double-click the downloaded file.
  3. Drag Talk Over onto Applications.
  4. Open Applications and double-click Talk Over.

First run

Allow microphone access when macOS asks.

Talk Over appears in your Dock and opens in your browser. That is normal: it uses the browser as its window but runs on your Mac. Voice-following needs microphone permission. Camera Take separately asks for camera permission. If you clicked Don't Allow, open System Settings → Privacy & Security → Microphone, enable your browser, and reload Talk Over.

Your first take

1. Add a script

Paste text and choose Prepare script, or import a .txt, .md, .markdown, or .rtf file.

2. Choose your mode

Use Voice for follow-along, Start for a timed crawl, or Manual for keyboard control.

3. Present

If you lose your place, click the next word you will say. Talk Over restarts from there.

# Talk Over - Install & Getting Started

Talk Over is a voice-following teleprompter for Apple Silicon Macs. Your scripts and audio stay on your Mac.

## What you need

- Apple Silicon Mac: M1, M2, M3, M4 or later. Intel Macs are not supported.
- macOS 11 Big Sur or later. macOS 13 or later recommended.
- About 250 MB free disk space.
- A built-in or external microphone for voice-following. A camera is optional for Camera Take.
- Internet only to download the app. Talk Over works offline.

## Install

1. Download the free trial or purchase Talk Over.
2. Double-click the downloaded file.
3. Drag Talk Over onto Applications.
4. Open Applications and double-click Talk Over.

## First run

Talk Over appears in your Dock and opens in your browser. This is normal: it uses the browser as its window but runs on your Mac. Allow microphone access when macOS asks if you want to use voice-following. Camera Take asks separately for camera permission.

If you clicked Don't Allow, open System Settings > Privacy & Security > Microphone, enable your browser, then reload the Talk Over page.

## Your first take

Paste text and choose **Prepare script**, or import a `.txt`, `.md`, `.markdown`, or `.rtf` file. Choose **Present**, then select Voice for follow-along, Start for a timed crawl, or Manual for keyboard control. If you lose your place, click the next word you will say.

How it works

Install it, then make it yours.

Download TalkOver, drag it to Applications, and start a script. No account, no separate voice download.

Before you download

Mac
Apple Silicon only — M1, M2, M3, M4 or later. Intel Macs aren't supported.
macOS
macOS 11 Big Sur or later. macOS 13+ recommended.
Space
About 250 MB free. Download is 64 MB; installed it's about 82 MB.
Microphone
Any built-in or external mic for voice-following. A camera only if you want to record yourself.
Internet
Needed only to download. TalkOver works fully offline after that. If you switch on automatic update checks inside the app, it also reads one small file on this site once each time it opens; nothing about you or your scripts is sent.
Scripts
Paste text, or import .txt, .md, .markdown, .rtf — up to 2 MB.

Install TalkOver

  1. Download the free trial or buy TalkOver.
  2. Double-click the downloaded file. A window opens showing the TalkOver icon and an Applications shortcut.
  3. Drag TalkOver onto Applications.
  4. Open Applications and double-click TalkOver.

The first time you open it

TalkOver opens in its own window and appears in the Dock, with a small TO icon in the menu bar. Everything runs on your Mac — turn your Wi-Fi off and it carries on working.

The first time you start voice-following, macOS asks for microphone permission — allow it. Recording asks separately for the camera. If you clicked Don't Allow, open System Settings → Privacy & Security, then turn TalkOver on under Microphone and again under Camera.

Start using it

Paste a script and choose Prepare Script, or drop in a file. Select Present, pick Voice on the left of the bar, then press Start Presenting — TalkOver listens and scrolls as you talk. Re-read a line and it understands where you are; skip lines you don't want to read, too.

Auto Scroll runs a steady timed crawl instead, and Manual lets you drive it with the arrow keys. You can switch between the three mid-read without starting over. Lost your place? Click the word you want to start from — TalkOver listens from there.

Keyboard shortcuts Space starts and pauses. Arrows nudge a line. Shift + arrow (or Page Up/Down) jumps most of a screen. Home/End jump to start or end. Plus/minus change crawl speed. ⌃⌥⌘F takes back a floating window that clicks are passing through. ⌃⌥⌘S lets a screen recording show the script, which is off by default.

How buying works

The trial and the paid version are two separate downloads. When you buy, you get the paid build — drag it into Applications over the trial and open it as usual.

Your scripts, settings and saved versions are already there, because they live in your own folder rather than inside the app. Updates arrive as a new Payhip download and an email when a new 1.x version is ready — no separate installer or activation involved.

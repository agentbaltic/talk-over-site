FAQ

Questions we get a lot

What does it cost?

$25, once. Not a subscription. That price is a founder rate while the app is new — it may go up later.

What happens after the 30-day trial?

TalkOver stops prompting. That's all it does — nothing is deleted, nothing is locked, and every script stays exactly where it was. Install the full version and your library is waiting.

How do I get the full version after I buy?

You download the paid version and drag it over the trial. Your library is already there, because it lives in your own folder, not inside the app.

What languages does it support?

Voice-following understands English (US) today. Timed scrolling and manual control already work with a script in any language — they just don't listen for it. More languages for voice-following are on the list for upcoming Version 1.x updates.

Does anything get uploaded?

No. Speech recognition runs entirely on your Mac. It works with the Wi-Fi off, and there's no account for anything to go to.

Will it run on my Mac?

Because it uses Apple's chips to process the audio, it will only run on Apple Silicon macs. Those are Macs with processor names like M1, M2, etc. If you've bought your Mac in the last four years, the chances are you have a Mac that runs TalkOver. Want to be sure? Just go to the Apple menu and select About This Mac. The first line says "Chip" and will tell you what processor it uses.

Can I use it with teleprompter glass?

Yes! We've built in mirroring (both horizontal and vertical) so if you're using a teleprompter with a built-in screen or one that uses a monitor to display the image, this will work perfectly. If you're using an external monitor with TalkOver, just set it to mirror your main monitor.

How do I get updates?

You'll get an email when an update is released and a link to download it. Just drop it into the Applications folder and you're good to go. It will ask if you want to replace the existing TalkOver app, say yes, and you're ready. All scripts are kept locally separate from the app so you won't lose any data.

Can I get a refund?

We built the 30-day free trial so you could use TalkOver for free and be sure it's right for you, and priced the full version so it's easy to say yes to. Because of that, we don't offer refunds once you've bought it. But if you're really unhappy for some reason, email us (See Contact) and let's talk. We don't like it when people are upset.

Is my script or recording sent anywhere?

No. Scripts, recognition, and any recording you make stay in your own folder on your own Mac. Nothing phones home.

What's coming next?

We have a lot of plans for TalkOver. Some of the new features we're working on are using an iPhone as a remote and using an iPad as a screen for a teleprompter, both of which will be in an update to TalkOver V1. Want to help make our roadmap? Reach out via the Contact link.

What happens when TalkOver 2 comes out?

Anyone who bought TalkOver 1 will get a VIP discount on the new version, and your current version never stops working. We don't know what the discount will be, because we have no idea what the price will be yet — but we'll take care of our users.

What if I have a problem or suggestion?

If you have a problem, let us know through the form on the Contact page. If you have a request, please use the same form. We love requests — adding new features is great, so don't hold back. You might not get a reply on new feature suggestions, but we add all of them to our product roadmap.

Still stuck? Send a message — we read every one and answer personally.
